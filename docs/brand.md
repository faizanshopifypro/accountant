# AP Accountax Ltd — Brand direction

## Positioning

Premium but approachable East London accountancy. Professional without corporate
navy. Affordable without looking cheap.

## Visual direction: "The Ledger"

Warm paper surfaces, charcoal structure, brass accents, hairline rules and
sequence numerals. Editorial serif display type with a clean sans for UI.

## Colour

| Role | Token | Hex | Notes |
|---|---|---|---|
| Ink | `--c-ink` | `#121417` | Headings, dark bands |
| Slate | `--c-slate` | `#2A2E33` | Primary actions, CTA band |
| Slate deep | `--c-slate-deep` | `#1C1F24` | Primary hover |
| Ivory | `--c-ivory` | `#FBF8F2` | Page canvas |
| Parchment | `--c-parchment` | `#F2EDE3` | Alternate sections |
| Card | `--c-card` | `#FFFDF9` | Elevated surfaces |
| Text | `--c-text` | `#2F3338` | Body on light |
| Muted | `--c-text-muted` | `#5E646C` | Secondary on light |
| On dark | `--c-on-dark` | `#FBF8F2` | Body on dark |
| On dark muted | `--c-on-dark-muted` | `#B4B9C0` | Secondary on dark |
| Accent text | `--c-accent-text` | `#8A6117` | Small brass text on light |
| Accent | `--c-accent` | `#B07E2E` | Rules, numerals, focus |
| Accent on dark | `--c-accent-on-dark` | `#C99A4A` | Brass on dark |

**Why not green.** An earlier forest-green direction read as organic / wellness.
Charcoal and slate keep the premium editorial system while signalling professional
services. Brass remains the only warm accent.

All pairings used in the UI were checked against WCAG 2.2 AA (4.5:1 text, 3:1 UI).

## Typography

- Display: Fraunces (variable, optical size)
- Text / UI: Manrope
- Temporary wordmark: "AP" mark + "AP Accountax" + tagline. Not an official logo.
