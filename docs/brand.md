# AP Accountax Ltd — Brand direction

## Positioning

Premium but approachable East London accountancy. Professional without generic
corporate navy-and-blue templates. Affordable without looking cheap.

## Official logo

Source file: `Logo/Elegant AP Accountax Branding.png`

Exported web assets (retina-ready PNGs):

- `assets/img/logo-*.png` — navy + peach on transparent (light surfaces)
- `assets/img/logo-on-dark-*.png` — ivory wordmark + peach on transparent (dark surfaces)

Do not replace these with typographic approximations while the official file exists.

## Colour (sampled from the logo)

| Role | Token | Hex | Notes |
|---|---|---|---|
| Ink / navy | `--c-ink` | `#0A1A2C` | Logo wordmark and icon frame |
| Slate | `--c-slate` | `#16324A` | Primary actions, CTA band |
| Slate deep | `--c-slate-deep` | `#0F2436` | Primary hover |
| Ivory | `--c-ivory` | `#FBF8F2` | Page canvas |
| Parchment | `--c-parchment` | `#F2EDE3` | Alternate sections |
| Card | `--c-card` | `#FFFDF9` | Elevated surfaces |
| Text | `--c-text` | `#1C2A38` | Body on light |
| Muted | `--c-text-muted` | `#5A6570` | Secondary on light |
| On dark | `--c-on-dark` | `#FBF8F2` | Body on dark |
| On dark muted | `--c-on-dark-muted` | `#B7C0C9` | Secondary on dark |
| Peach | `--c-accent` | `#F9A470` | Logo bars, swoosh, rules |
| Accent text | `--c-accent-text` | `#A84F22` | Small peach-derived text on light |
| Focus on light | `--c-accent-focus` | `#A84F22` | ≥3:1 on ivory |

Bright logo peach (`#F9A470`) is used for decorative accents and dark-surface
highlights. Small text on light surfaces uses the darker terracotta so contrast
stays at WCAG 2.2 AA.

## Typography

- Display: Fraunces (pairs with the logo’s serif wordmark)
- Text / UI: Manrope (pairs with the logo’s sans tagline)
