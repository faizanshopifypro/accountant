## Review scores
Score each category from 1–10. Use evidence and specific observations, not intuition alone.

| Category | Weight | Score | Evidence / notes |
|---|---:|---:|---|
| Visual identity and composition | 20% | /10 | |
| Layout, spacing and alignment | 15% | /10 | |
| Typography and hierarchy | 10% | /10 | |
| UX and user journey | 15% | /10 | |
| Responsive behavior | 15% | /10 | |
| Interaction and functionality | 10% | /10 | |
| Accessibility | 5% | /10 | |
| Code quality and performance | 10% | /10 | |

Weighted score = sum(weight × score ÷ 10).

## Critical gates
- [ ] No broken primary user journey.
- [ ] No blocker/high-severity defect.
- [ ] Responsive behavior checked.
- [ ] Keyboard and focus behavior checked.
- [ ] Required automated checks passed.
- [ ] Actual rendered UI inspected where tooling is available.
- [ ] No fabricated claims, data, or assets.
- [ ] Known limitations disclosed.
